Helix Vizforge Lite

Charts for uGUI that you can ship. This is the free edition: seven chart types on the Canvas renderer, with the same API as the full edition.

Getting started

  1. Import the package. Everything lands under Assets/Helix.
  2. Open Samples/Scenes/BasicChartsDemo.unity to see it running.
  3. In your own scene: add a ChartView component to a GameObject under a Canvas, assign a DatasetAsset, and pick a chart kind in the inspector.

From code

var data = new Dataset();
data.AddSeries("Month", new[]{ "Jan","Feb","Mar","Apr" });
data.AddSeries("Sales", new[]{ 120.0, 180.0, 90.0, 240.0 });

ChartView.Create(canvas.transform)
         .WithData(data)
         .Line("Month", "Sales");

What the full edition adds

The chart types below are not implemented in this package - the generator classes are absent from the assembly, so there is no setting here that enables them. They stay listed in the inspector so you can see what the full edition covers; picking one draws a line chart and logs a note explaining why.

  • Bar family - Horizontal Bar, Stacked Bar, Grouped Bar, Waterfall, Funnel
  • Radial - Pie, Donut, Radar, Polar, Sunburst
  • Statistical - Histogram, Box Plot, Violin, Heatmap, Gauge, Progress
  • Relational - Parallel Coordinates, Treemap, Sankey, Timeline, Gantt
  • 3D - Bar3D, Scatter3D, Surface3D
  • Renderers - UI Toolkit and world-space surfaces (Lite is uGUI only)
  • Data - CSV and JSON import, data sources and transform pipeline
  • Modules - dashboards, analytics, BI, financial, scientific, telemetry and export
  • Theming - the built-in theme preset library
