CHAPTER 01

Start here: Checkers Club

Checkers Club is a standalone editable Unity game template. Tap one of your checkers, then a highlighted legal destination. Captures are mandatory and a multi-jump must continue with the same piece. Reach the far rank to crown a king. The ladder introduces Classic, Flying Kings, Giveaway and Grand rules; Giveaway reverses the objective, while Grand uses a 10 by 10 board and longest captures. Combo Puzzles are separate win-in-N positions. All opponents are local computer players.

Includes 25 curated opponents, source-backed generation, a game-specific visual editor and validation, 4 guided helpers, local saving and portrait/landscape scenes. Keep the required private game Kit and publisher-owned Szekipapa77Ads layer. Provider SDK binaries are excluded. There is no bundled HLK, purchases, multiplayer server or remote LiveOps backend. Additional included libraries: 21 puzzles. Import only one game Kit into a project because the Kit classes share names.

CHAPTER 02

Requirements, installation and first play

Use Unity 6000.0.62f1, URP 17.0.4 and Unity UI 2.0.0. Install matching Android SDK/NDK/OpenJDK and WebGL modules in Unity Hub. Retain the supplied manifest and ProjectSettings.

  1. Extract the standalone project to a short writable local path, then open it in the matching editor. Wait for package import and compilation.
  2. For native unitypackage import, create a matching URP project and use Assets > Import Package > Custom Package. Import every game, Kit, Szekipapa77Ads and WebGL-template entry.
  3. Run Szekipapa77 > Checkers Club > Setup. It configures rendering and player settings; review its changes when integrating with existing work.
  4. Active Input Handling must support the classic Input Manager: choose Old or Both. New Input System only is insufficient.
  5. Open Assets/Games/CheckersClub/Scenes/CheckersClub_Mobile.unity and press Play. Follow the level card and first-level instructions.
  6. Stop Play mode before editing level assets. Keep all .meta GUIDs. The game uses classic Unity UI Text; do not assume an extra TextMesh Pro import is required.

Tap one of your checkers, then a highlighted legal destination. Captures are mandatory and a multi-jump must continue with the same piece. Reach the far rank to crown a king. The ladder introduces Classic, Flying Kings, Giveaway and Grand rules; Giveaway reverses the objective, while Grand uses a 10 by 10 board and longest captures. The initial bank has 25 curated opponents. Read the supplied loader/generator before changing continuation rules. Play the guided opening, ordinary progress, completion and retry paths; preserve saved indexes during a visual reskin. The Mobile scene is portrait and the WebGL-named scene is landscape, but the supplied Build menu selects portrait for both build targets. Select landscape explicitly in your Build Profile if desired. Test a near-startup scene replacement as well as a normal restart.

Install Unity 6000.0.62f1 Android modules through Hub. Select Android, run Setup and review application ID com.szekipapa77.checkersclub, version, scene orientation and signing. The build command writes Builds/Android/checkersclub.apk. Confirm BuildResult.Succeeded and the actual output file; intermediate report totals are not the final APK size.

Use your own keystore/signing and distribution settings. A test-signed demo is not a signed store release. A provider-free build simulates ads; a provider test-demo does not prove production ad-account configuration. Test real hardware touch, safe areas, focus/audio, save/relaunch and reward callbacks. Keep passwords, keystores and private service credentials out of buyer packages.

CHAPTER 16

Troubleshooting

Compile errors: restore matching packages and the full private Kit/Ads layer; only one game Kit belongs in a project. Pink/invisible rendering: run Setup and inspect Graphics and every Quality URP assignment. No input: classic input handling must be enabled; check canvas focus and blocking modals. Missing resources: restore exact paths, .meta GUIDs and importer settings.

Edits do not appear: stop Play, Save in the level editor, reload the canonical bank and check current saved level. Text reverts: update construction and refresh assignments from the exact table. No live ads: provider binaries are deliberately excluded; inspect your installed provider and fallback mode. Scene reload exception: retain owner-lifetime and generation guards on delayed callbacks. WebGL fails: inspect browser Console, compression headers and missing payloads.
