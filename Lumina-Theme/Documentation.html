Lumina Theme

UI theming, design tokens & WCAG accessibility for Unity.

Unity 6000.0.62f1+Any render pipeline ScriptableObjectWCAG AA / AAA

1. Overview

Lumina Theme is a lightweight theming engine built on design tokens (colors, gradients, numbers, fonts, sprites, audio) stored in a LcTheme ScriptableObject. Author themes visually with the Theme Designer, verify contrast against WCAG AA/AAA as you work, and drive your own UI from a single source of truth. Pure C# — no render-pipeline dependency.

2. Requirements

  • Unity 6000.0.62f1 or newer.
  • No other dependencies — Built-in RP, URP and HDRP projects all work.

3. Quick start

  1. Create a theme asset:
Assets ▸ Create ▸ Lucent UI ▸ Theme Preset ▸ Dark

(Also available: Light, High Contrast, and Assets ▸ Create ▸ Lucent UI ▸ Palette.)

  1. Open the visual editor and tune colors with live contrast feedback:
Window ▸ Lucent UI ▸ Theme Designer
  1. Reference the LcTheme from your scripts and resolve tokens (below).

4. Using a theme in code

Resolve design tokens

using Lucent.Theme;
using UnityEngine;

public class Panel : MonoBehaviour
{
    public LcTheme theme;   // assign your Theme asset in the Inspector

    void Start()
    {
        if (theme.TryResolveColor("surface", out Color32 bg))
            GetComponent<UnityEngine.UI.Graphic>().color = bg;

        float radius = theme.ResolveNumber("radius.card", 12f);
    }
}

Build a theme at runtime

using Lucent.Theme;

LcTheme dark  = LcSemanticThemes.CreateDark();
LcTheme light = LcSemanticThemes.Create(LcThemeId.Light);
LcTheme hc    = LcSemanticThemes.CreateHighContrast();

dark.SetColor("accent", new UnityEngine.Color32(63, 224, 255, 255));
string json = dark.ExportJson();   // persist / ship a theme as JSON

5. Accessibility — LcContrast

Static WCAG helpers for verifying and choosing readable color pairs.

using Lucent.Theme;
using UnityEngine;

float ratio = LcContrast.Ratio(foreground, background);   // e.g. 7.1
bool  aa    = LcContrast.MeetsAA(foreground, background);          // ≥ 4.5 (or 3.0 large)
bool  aaa   = LcContrast.MeetsAAA(foreground, background, largeText:true);
MethodReturns
RelativeLuminance(Color)WCAG relative luminance.
Ratio(Color a, Color b)Contrast ratio (1–21).
MeetsAA(fg, bg, largeText=false)WCAG AA pass/fail.
MeetsAAA(fg, bg, largeText=false)WCAG AAA pass/fail.

6. Palettes

LcPalette groups named colors (with an optional color-blind-safe variant). Import from common formats with LcPaletteImport:

using Lucent.Theme;

LcPalette p = LcPaletteImport.Import(fileText);      // auto-detects format
// or: FromHexList / FromGpl (GIMP) / FromCssVariables
theme.AddPalette(p);

7. Notes

This pack is the theming engine + tooling: create, validate and query themes, and drive your own UI from them. Lumina widgets that automatically re-skin themselves from the active theme are distributed separately.
