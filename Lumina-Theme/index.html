Lumina Theme Unity 6000.0.62f1+

One source of truth for UI colors, gradients, sizes, fonts and sounds — with contrast checking built into the authoring loop.

Overview

Lumina Theme is a lightweight theming engine for Unity. It keeps UI colors, gradients, numbers, fonts, sprites and audio references in ScriptableObject theme assets, gives you a visual Theme Designer window, and includes WCAG AA/AAA contrast helpers so readability is something you check while designing rather than after a QA pass.

  • Token-based themes — one LcTheme asset holds colors, gradients, numbers, fonts, sprites and audio under stable string keys.
  • Theme Designer window — edit every token category with a live preview, full Undo support, and one-click semantic presets.
  • WCAG contrast — LcContrast computes relative luminance and contrast ratios and answers AA/AAA directly.
  • Palettes — multiple named palettes per theme, each with an optional color-blind-safe variant you can flip globally.
  • Five built-in themes — Dark, Light, High Contrast, Scientific and Financial, generated in code.
  • Import / export — versioned JSON round-trip, plus palette import from GIMP .gpl, hex lists and CSS custom properties.
  • Runtime switching — LcThemeManager swaps the active theme and rebinds every consumer.

The package is pure C#, source-included and render-pipeline independent. It installs under Assets/Lucent.

Scope. Lumina Theme is the theming engine, not the full Lucent UI suite. It does not ship widgets, shapes or effects, and it does not automatically restyle third-party UI. It gives you the token store, the authoring tool and the binding API; you decide what reads from it. The Runtime Switching section shows the two-line consumer pattern.

The Theme Asset

LcTheme is a ScriptableObject. Create one per visual identity — usually one per shipped theme, not one per screen.

Assets → Create → Lucent UI → Theme        // creates "LcTheme.asset"

Reading tokens

Every category has a TryResolve* method that reports whether the key existed, and colors additionally have convenience getters that fall back rather than fail.

using Lucent.Theme;

// Falls back to the theme's FallbackColor if the key is missing
Color32 bg = theme.ResolveColor(LcColorKeys.Background);

// Falls back to a value you choose
Color32 accent = theme.ResolveColor(LcColorKeys.Accent, Color.magenta);

// Branch on presence
if (theme.TryResolveColor(LcColorKeys.Focus, out Color32 focus))
    outline.color = focus;

float radius = theme.ResolveNumber(LcNumberKeys.RadiusMd, 8f);

if (theme.TryResolveGradient(LcGradientKeys.Primary, out LcGradientToken g)) { /* ... */ }
if (theme.TryResolveFontAsset(LcAssetKeys.FontDefault, out Font font)) { /* ... */ }
if (theme.TryResolveSprite(LcAssetKeys.SpriteCheck, out Sprite check)) { /* ... */ }
if (theme.TryResolveAudio(LcAssetKeys.AudioClick, out LcAudioToken click)) { /* ... */ }

Writing tokens

theme.SetColor(LcColorKeys.Primary, new Color32(124, 58, 237, 255));
theme.SetNumber(LcNumberKeys.RadiusLg, 16f);
theme.SetFont(LcAssetKeys.FontDefault, myFont, sizeScale: 1.1f);
theme.SetSprite(LcAssetKeys.SpriteChevron, chevronSprite);
theme.SetAudio(LcAssetKeys.AudioClick, clickClip, volume: 0.8f);
theme.SetGradient(myGradientToken);

Each setter marks the theme changed and raises Changed, so bound UI updates without an explicit refresh call.

Gradient tokens

LcGradientToken carries a shape (LcGradientShape), an angle in degrees, and either a stop array or four corner colors:

FieldMeaning
ShapeLinear, angular, corner-4 and related shapes.
AngleDegrees — linear direction, or the angular reference.
StopsLcColorStop[] — each a Position (0–1) and a Color.
C0…C3Corner-4 colors: bottom-left, bottom-right, top-right, top-left.

Keys are plain strings, so nothing stops you defining your own namespace — color.brand.hero, spacing.card.gutter — alongside the standard set.

Palettes

A theme can hold several named palettes. Only one is active at a time (ActivePalette), which makes a palette the right unit for a seasonal recolour, a per-faction tint, or a light/dark pair that shares every non-color token.

using Lucent.Theme;

var palette = new LcPalette("winter", winterColors, winterColorBlindSafe);
theme.AddPalette(palette);
theme.ActivePalette = "winter";

Color-blind-safe variants

Each palette may carry a parallel ColorBlindSafe array. Flipping one flag on the theme swaps every palette to its safe variant — no per-color branching in your UI code:

theme.UseColorBlindSafe = accessibilityOptions.colorBlindMode;

// Per-palette query
if (palette.HasColorBlindSafe)
    palette.TryResolve(LcColorKeys.Success, colorBlindSafe: true, out Color32 c);
Design tip. A color-blind-safe variant is most valuable on the status colors — Success, Warning, Error, Info — where red/green is doing the semantic work. Pair the recolour with a shape or icon difference; color alone is never sufficient for WCAG.

WCAG Contrast

LcContrast implements the WCAG 2.x relative-luminance and contrast-ratio formulas. It is a static class over plain colors — usable in a test, in an editor tool, or at runtime.

using Lucent.Theme;

float ratio = LcContrast.Ratio(foreground, background);   // 1.0 .. 21.0

bool okBody    = LcContrast.MeetsAA(foreground, background);
bool okHeading = LcContrast.MeetsAA(foreground, background, largeText: true);
bool strict    = LcContrast.MeetsAAA(foreground, background);

float luminance = LcContrast.RelativeLuminance(background);
ThresholdConstantRatioApplies to
AA, normal textLcContrast.AaNormal4.5 : 1Body copy
AA, large textLcContrast.AaLarge3 : 1≥ 18pt, or 14pt bold
AAA, normal textLcContrast.AaaNormal7 : 1Body copy, strict
AAA, large textLcContrast.AaaLarge4.5 : 1Headings, strict

Guard your theme in CI

Because the checks are pure functions over a theme's tokens, contrast becomes a unit test rather than a review comment:

[Test]
public void BodyTextMeetsAaOnEverySurface()
{
    var theme = LcSemanticThemes.Create(LcThemeId.Dark);
    Color32 text = theme.ResolveColor(LcColorKeys.Text);

    Assert.IsTrue(LcContrast.MeetsAA(text, theme.ResolveColor(LcColorKeys.Background)));
    Assert.IsTrue(LcContrast.MeetsAA(text, theme.ResolveColor(LcColorKeys.Surface)));
    Assert.IsTrue(LcContrast.MeetsAA(text, theme.ResolveColor(LcColorKeys.SurfaceAlt)));
}
Alpha. The WCAG formula is defined for opaque colors. Composite any translucent foreground over its actual backdrop before measuring, otherwise the ratio describes a color nobody sees.

Runtime Switching

LcThemeManager is a static hub holding the active theme and rebinding consumers when it changes.

using Lucent.Theme;

LcThemeManager.SetActiveTheme(myDarkTheme);       // by asset
LcTheme light = LcThemeManager.SetActiveTheme(LcThemeId.Light);   // by built-in id

LcTheme active = LcThemeManager.Active;
bool has       = LcThemeManager.HasActiveTheme;
int consumers  = LcThemeManager.ConsumerCount;

LcThemeManager.ClearActiveTheme();

The consumer pattern

A consumer holds an optional theme reference and asks the manager for the effective one. Effective returns the bound theme when there is one and the global active theme otherwise — so a widget can override its theme locally without any extra branching:

public sealed class MyPanel : MonoBehaviour
{
    [SerializeField] LcTheme _theme;      // optional local override

    void OnEnable()  { LcThemeManager.Changed += Restyle; Restyle(); }
    void OnDisable() { LcThemeManager.Changed -= Restyle; }

    void Restyle()
    {
        LcTheme theme = LcThemeManager.Effective(_theme);
        if (theme == null) return;

        background.color = theme.ResolveColor(LcColorKeys.Surface);
        label.color      = theme.ResolveColor(LcColorKeys.Text);
    }
}

Rebinding

RebindAll(theme) pushes a theme onto every live consumer and returns how many it touched — a useful assertion in a test, and a useful log line when a theme swap appears to do nothing.

int rebound = LcThemeManager.RebindAll(newTheme);
Debug.Log($"Rebound {rebound} consumers");

JSON & Palette Import

Theme JSON

Themes round-trip through a versioned JSON document (schema: "lucent.theme", version 1) carrying colors, gradients, numbers, font/sprite/audio references and all palettes.

using Lucent.Theme;

string json = theme.ExportJson();
theme.ExportJsonFile(Application.dataPath + "/theme.json");

bool ok = theme.ImportJson(json);      // false if the document is invalid

// Or drive the serializer directly
string doc = LcThemeJson.Export(theme);
LcThemeJson.Import(theme, doc);
Asset references across JSON. Fonts, sprites and audio clips are serialised as references, not embedded binaries. Exporting a theme and importing it into a project that lacks those assets restores every color and number, and leaves the asset slots empty. Colors, gradients and numbers are always fully portable.

Palette import

LcPaletteImport reads palettes from formats designers already produce — no manual retyping of hex codes.

using Lucent.Theme;

// Detect the format automatically
LcPalette p = LcPaletteImport.Import(fileText, paletteName: "brand");

// Or be explicit
LcPalette gpl = LcPaletteImport.FromGpl(gimpText, "brand");        // GIMP .gpl
LcPalette hex = LcPaletteImport.FromHexList(hexText, "brand");      // one hex per line
LcPalette css = LcPaletteImport.FromCssVariables(cssText, "brand"); // --token: #rrggbb

LcPaletteFormat detected = LcPaletteImport.Detect(fileText);

if (LcPaletteImport.TryParseCssColor("#7C3AED", out Color32 c)) { /* ... */ }

The Theme Designer exposes the same importer behind a file picker accepting gpl, txt, css, hex and csv.

Open it from either Window → Lucent UI → Theme Designer or Tools → Lucent UI → Theme Designer.

Assign a theme at the top of the window; everything below edits that asset in place, and every edit is recorded with Undo, so Ctrl+Z behaves exactly as it does in the inspector.

One-click Dark, Light and High Contrast buttons load a complete built-in theme into the asset you are editing — the fastest way to get a coherent starting point before customising.

A preview strip renders representative UI with the current tokens, so a change to color.surface or radius.md is visible immediately, without entering play mode.

Applying a theme across the scene

LcThemeApply.Apply(theme) walks the scene and assigns the theme to every component exposing an LcTheme serialized field — public or [SerializeField] private — returning the number of components it touched.

int touched = LcThemeApply.Apply(myTheme);

FAQ & Troubleshooting

Does this automatically restyle my existing UI?

No, and that is deliberate. Lumina Theme is the token store and authoring tool; you decide which components read from it. The consumer pattern in Runtime Switching is about eight lines. LcThemeApply.Apply automates assigning the theme to components that already expose an LcTheme field.

Every color comes back the same wrong colour.

That is FallbackColor — the key is missing. Check spelling against the LcColorKeys constants, and confirm ActivePalette names a palette that actually exists.

I changed a token from code but nothing updated.

The setters raise Changed automatically. If you mutated an array in place instead, call MarkChanged(). Also confirm your consumer subscribed to LcThemeManager.Changed.

A theme swap did nothing.

Check the return value of RebindAll, or read ConsumerCount. Zero means no consumer is subscribed — usually a component that subscribes in OnEnable but was never enabled.

Which contrast threshold applies to my label?

Large text is 18pt or larger, or 14pt bold; everything else is normal text. When unsure, use the normal-text threshold — it is stricter.

My exported JSON lost the fonts.

Expected. Asset references cannot survive a plain JSON document into a project that lacks those assets. Colors, gradients and numbers always round-trip.

Can several themes be active at once?

One global active theme, plus any number of local overrides. A component with its own LcTheme reference keeps it; Effective() resolves the precedence.

Is it safe with managed code stripping?

Yes. Token lookup is dictionary-based over strings, not reflection over types.
