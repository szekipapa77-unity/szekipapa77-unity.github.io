CHAPTER 01

Start here: Bouncy Blob

Bouncy Blob is a standalone editable Unity game template. Hold the input to charge the jelly blob, then release to launch the sun-berry along the course aim. Guide its launch into the glass jar from above. The course uses the BBWorld deterministic simulation; obstacles and target placement change the required release timing. Retry a missed launch and inspect the level goal.

Includes 25 curated levels, source-backed generation, a game-specific visual editor and validation, 4 guided helpers, local saving and portrait/landscape scenes. Keep the required private game Kit and publisher-owned Szekipapa77Ads layer. Provider SDK binaries are excluded. There is no bundled HLK, purchases, multiplayer server or remote LiveOps backend. Import only one game Kit into a project because the Kit classes share names.

CHAPTER 02

Requirements, installation and first play

Use Unity 6000.0.62f1, URP 17.0.4 and Unity UI 2.0.0. Install matching Android SDK/NDK/OpenJDK and WebGL modules in Unity Hub. Retain the supplied manifest and ProjectSettings.

  1. Extract the standalone project to a short writable local path, then open it in the matching editor. Wait for package import and compilation.
  2. For native unitypackage import, create a matching URP project and use Assets > Import Package > Custom Package. Import every game, Kit, Szekipapa77Ads and WebGL-template entry.
  3. Run Szekipapa77 > Bouncy Blob > Setup. It configures rendering and player settings; review its changes when integrating with existing work.
  4. Active Input Handling must support the classic Input Manager: choose Old or Both. New Input System only is insufficient.
  5. Open Assets/Games/BouncyBlob/Scenes/BouncyBlob_Mobile.unity and press Play. Follow the level card and first-level instructions.
  6. Stop Play mode before editing level assets. Keep all .meta GUIDs. The game uses classic Unity UI Text; do not assume an extra TextMesh Pro import is required.

CHAPTER 04

Gameplay, controls and progression

Hold the input to charge the jelly blob, then release to launch the sun-berry along the course aim. Guide its launch into the glass jar from above. The course uses the BBWorld deterministic simulation; obstacles and target placement change the required release timing. Retry a missed launch and inspect the level goal.

The initial bank has 25 curated levels. Read the supplied loader/generator before changing continuation rules. Play the guided opening, ordinary progress, completion and retry paths; preserve saved indexes during a visual reskin. The Mobile scene is portrait and the WebGL-named scene is landscape, but the supplied Build menu selects portrait for both build targets. Select landscape explicitly in your Build Profile if desired. Test a near-startup scene replacement as well as a normal restart.

CHAPTER 06

Visual level editor: worked editing session

Open Szekipapa77 > Bouncy Blob > Level Editor. Exact implementation: Editor/BouncyBlobLevelEditor.cs.

Open the Bouncy Blob editor and select an early level. Use Dup or Duplicate before editing. Change its visible name and one rule or board element with the exact controls below. Save explicitly and run the current entry through the editor validation and play controls. The per-game source-control table includes the current brush, geometry, target, rule and AI fields; do not treat hierarchy or resource IDs as display text.

  1. Back up Resources/bouncyblob/Levels/levels.json.
  2. Duplicate a simple early level and edit one small element.
  3. Use the game-specific validation controls and resolve every reported issue.
  4. Save explicitly; stop and restart Play mode, then use Play this level or navigate to the edited index.
  5. Check portrait and landscape and rebuild demo outputs after accepting data changes.

The exact current authoring controls, including tooltips and generator switches, follow. These are game-specific source references, not a generic editor feature list.
