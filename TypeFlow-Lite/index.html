TypeFlow Lite

Correct Arabic, Hebrew and right-to-left text on the TextMeshPro you already use. One component, no migration, no native binaries. This is the free edition of TypeFlow Pro - the correctness half, complete.

Arabic in ten seconds

  1. Import the package. Everything lands under Assets/TypeFlowPro.
  2. Select any object with a TextMeshPro or TextMeshProUGUI component.
  3. Add TypeFlow Text. Type Arabic - letters join into their contextual forms and the line reads right-to-left.

Remove the component and you are back to vanilla TextMeshPro. Nothing is rewritten, no scene is migrated, and your own text stays your own text.

Open Demos/TypeFlowLiteDemo.unity to see it running: each row shows the same string with TypeFlow Text on top and plain TextMeshPro below.

Without a component

If you already have an "RTL fixer" in your project, one call replaces it:

using TypeFlowPro;

string visual = TypeFlowRtl.Convert(logicalText);
// Arabic shaping + lam-alef ligatures + full UAX #9 bidi.
// Assign to any TextMeshPro, TextMeshProUGUI or UI Text.

What this edition does

Arabic joiningInitial, medial, final and isolated forms chosen from context, with lam-alef ligatures.
HebrewThe same bidirectional pass; no separate setup.
Bidirectional orderFull UAX #9, so Latin, numbers and punctuation inside an Arabic paragraph keep their own order.
Digit shapingASCII, Arabic-Indic or Persian digits, always or only in Arabic context - four modes on the component.
AlignmentLeft and right alignment auto-flip for a right-to-left paragraph.
MarkdownOptional conversion of simple Markdown to TMP rich text.
TagsTextMeshPro's own rich-text tags pass through untouched, and the animation tags of the full edition are parsed and stripped rather than shown as literal text.
SourceComplete C#, no DLLs, no native binaries, no runtime allocation in the steady state.
TestsEdit-mode tests covering the RTL pipeline and the processor.

Component settings

Base DirectionAuto, LTR or RTL. Auto uses the first strong character, per UAX #9.
Enable Arabic ShapingContextual joining. Turn it off for a pure bidi reorder.
DigitsNone, NativeArabic, NativePersian, ContextualArabic or ContextualPersian.
MarkdownConverts simple Markdown before shaping.

Fonts

TypeFlow Lite shapes text; it does not rasterise it. Any TextMeshPro font asset works, as long as its atlas actually contains the Arabic presentation forms. The package bundles Amiri (SIL Open Font License 1.1) and a ready-made TMP font asset so the demo renders out of the box - see Third-Party Notices.txt.

If Arabic shows as boxes, the font atlas is missing glyphs rather than the shaper being wrong. Tools > TypeFlow Lite has an Arabic font diagnostics window that says which characters your atlas is missing.

What the full edition adds

The features below are not implemented in this package - their scripts are absent from the assemblies, so no setting here can switch them on. They stay listed in the inspector so the line between the editions is visible from inside the tool.

  • TypeFlow Animator - an RTL-aware typewriter that reveals in logical reading order, with per-word reveal, pacing and dialogue actions.
  • Twenty behaviour tags - wave, shake, rainbow, jitter and the rest, plus per-span entrance and disappearance animations.
  • The Kiln engine - a pure-C# OpenType renderer with GSUB/GPOS, variable fonts, colour emoji and SDF/MSDF rasterising, with no TextMeshPro at all.
  • Font families, links and inline effects - faux-bold and faux-italic families, clickable link regions, gradients.
  • Damage numbers - a pooled combat-text system with style assets and motion curves.
  • 3D, curved and decal text.
  • The Unicode segmentation suite - grapheme, line, word and sentence breaking, with the conformance runner.

Required packagecom.unity.textmeshpro (or the TextMeshPro inside com.unity.ugui on Unity 6)

Known limits

  • Tier 1 only: the animator and the Kiln engine are full-edition features.
  • The Unicode segmentation suite - grapheme, line, word and sentence breaking - is a full-edition feature. Bidirectional ordering and Arabic shaping are complete here.
  • Indic reordering, kashida justification and the OpenType shaper are full-edition features. Arabic and Hebrew are complete here.
  • Lite and the full edition install to the same folder and share asset GUIDs. If you upgrade later, delete Assets/TypeFlowPro before importing the full edition.

Third-party content

Amiri (SIL Open Font License 1.1) and C# tables derived from the Unicode Character Database. Both are documented in full, with licence text, in Third-Party Notices.txt in the package root. No DLLs, no native binaries, no third-party audio or images, and no AI-generated content of any kind.
