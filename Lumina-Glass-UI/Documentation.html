Lumina Glass UI Unity 6000.0.62f1+

GPU frosted panels, refractive glass, and six composable geometry effects on ordinary uGUI elements.

Overview

Lumina Glass UI brings the frosted-glass panel and the soft-shadow/glow vocabulary of modern OS interfaces to Unity's uGUI, without render textures, without a second camera, and without pre-baked shadow sprites.

  • Blur panel — a real GPU backdrop blur with vibrancy, tint, grain and four quality levels.
  • Liquid glass — refraction, chromatic aberration, edge glint, gloss and a bevel with a controllable light angle.
  • Drop shadow — offset, blur and spread cast from the element's real silhouette.
  • Glow — uniform or per-side reach, additive blending, four named presets and an animated pulse.
  • Outline — inner/center/outer alignment, drawn above or below the glow.
  • Neumorphism & inner shadow — the paired light/dark cast, and inset depth.
  • URP auto-installer — one menu command wires the blur renderer feature into every active renderer.
  • Built-in RP fallback — a CommandBuffer path so blur is not URP-only.

Silhouette-accurate, not box-accurate

Every effect is cast from the element's actual outline via ILcSilhouetteSource, not from its bounding box. A shadow under a circle is round; a glow around a star has points. This is the difference from Unity's built-in Shadow and Outline components, which duplicate the mesh at an offset and cannot soften or spread.

Scope. Lumina Glass UI is the effects pack. It bundles the Lucent render spine, shape generators, motion engine and theme runtime because the effects depend on them — so procedural shapes are included and usable. It does not include the full shape authoring tooling of Lumina Shapes, the Theme Designer of Lumina Theme, or any widgets, charts or scroll views.

Blur Setup (URP)

The blur reads the scene colour behind the panel, which under URP requires a renderer feature. One menu command installs it into every active renderer:

Tools → Lucent UI → Install Blur Renderer Feature

The command is validated — it greys out when the project has no URP target — and it is idempotent, so running it twice does not produce two features.

using Lucent.Effects;   // editor assembly

bool installed = LcBlurAutoInstaller.IsFeatureInstalled();
bool hasUrp    = LcBlurAutoInstaller.HasUrpTarget();

int count = LcBlurAutoInstaller.InstallIntoActiveRenderers(silent: true);

Query support at runtime before promising a frosted look:

if (blurPanel.IsSupported) { /* real backdrop blur */ }
else                       { /* fall back to a plain translucent fill */ }

// Underlying capability flags
LcPipeline pipeline = LcCapabilities.ActivePipeline;   // BuiltIn | Urp | Hdrp | Unknown
bool grab           = LcCapabilities.SupportsSceneColorGrab;
bool compute        = LcCapabilities.SupportsCompute;
WebGL and shader stripping. Blur shaders must survive the build. Keep them reachable — the package places them under a Resources folder for exactly this reason — or add them to Always Included Shaders. A panel that blurs in the editor and renders flat in a WebGL build is almost always a stripped shader.

Blur Panel

LcBlurPanel is the frosted surface. Add it: Add Component → Lucent UI → Effects → Lc Blur Panel, or create one ready-made with GameObject → Lucent UI → Effects → Blur Panel.

using Lucent.Effects;

var panel = go.AddComponent<LcBlurPanel>();

var spec = panel.Spec;
spec.Radius       = 24f;
spec.Vibrancy     = 1.2f;
spec.Tint         = new Color32(255, 255, 255, 24);
spec.Opacity      = 0.9f;
spec.Quality      = LcBlurQuality.High;
spec.CornerRadius = 20f;
spec.Squircle     = true;
panel.Spec = spec;          // assigning re-applies

panel.Apply();              // or force a refresh explicitly
LcBlurPanelSpecMeaning
RadiusBlur radius in pixels — the main cost driver.
VibrancySaturation boost on the blurred backdrop, as in a translucent OS panel.
BrightnessLightens or darkens the backdrop.
TintColour wash over the blur; alpha is its strength.
Grain0–1 film grain — hides banding on large soft gradients.
Opacity0–1 overall panel opacity.
QualityLow, Medium, High, Ultra.
CornerRadiusRounded corners on the panel itself.
SquircleContinuous-curvature corners instead of circular.
SuperellipseExponentSquircle sharpness (minimum 2).
BlurUiBehindAlso blur UI drawn behind the panel, not just the scene.

Quality

LcBlurQualityUse for
LowLow-end mobile, or many simultaneous panels.
MediumGeneral mobile default.
HighDesktop and console default.
UltraHero surfaces, large radii, marketing shots.

Grain is the cheap fix for banding: a large radius over a smooth gradient will band on 8-bit displays, and a small amount of grain dithers it away far more cheaply than raising quality.

Liquid Glass

LcGlass extends LcBlurPanel, so it has every blur setting plus the optical layer that makes a surface read as glass rather than as frosted plastic.

Add it: Add Component → Lucent UI → Effects → Lc Glass, or GameObject → Lucent UI → Effects → Liquid Glass Card.

using Lucent.Effects;

var glass = go.AddComponent<LcGlass>();

var g = glass.GlassSpec;
g.Refraction          = 0.04f;
g.ChromaticAberration = 0.01f;
g.EdgeGlint           = 0.8f;
g.Gloss               = 0.35f;
g.BevelWidth          = 6f;
g.LightAngle          = 135f;
g.NativeShadow        = true;
glass.GlassSpec = g;
LcGlassSpecRangeMeaning
Refraction≥ 0How much the backdrop bends through the panel.
ChromaticAberration≥ 0Per-channel refraction split — the colour fringe at the edge.
EdgeGlint0–2Bright specular catch along the rim.
Gloss0–1Surface sheen — matte at 0, polished at 1.
BevelWidth≥ 0Width of the shaped edge that catches light.
LightAngle0–360Direction of the virtual light, in degrees.
NativeShadowboolEnable the built-in drop shadow (glass.Shadow).
Keep one light angle. LightAngle is per-panel, which means it is possible — and always wrong — to light two glass cards from different directions in the same screen. Pick one angle for the project and set it everywhere; inconsistent lighting is the single biggest tell that a glass UI is fake.

Start subtle. Refraction around 0.02–0.05 reads as real glass; much more and text behind the panel becomes unreadable, which is a legibility problem, not a style.

Drop Shadow

LcShadow casts a soft shadow from the element's real silhouette.

Add it: Add Component → Lucent UI → Effects → Lc Shadow, or GameObject → Lucent UI → Effects → Shadowed Panel.

using Lucent.Effects;

var shadow = go.AddComponent<LcShadow>();

shadow.Spec.Color  = new Color32(0, 0, 0, 90);   // alpha is the strength
shadow.Spec.Offset = new Vector2(0f, -4f);       // y down = light from above
shadow.Spec.Blur   = 12f;
shadow.Spec.Spread = 2f;
LcDropShadowEffectDefaultMeaning
Color35% blackTint; alpha is overall strength.
ColorToken""Theme colour token; overrides Color when a theme is bound.
Offset(0, -4)Surface-local pixels; x right, y up.
Blur8Soft falloff radius in pixels.
Spread0Dilate the silhouette before blurring.
BlendNormalCompositing mode for the pass.
CustomMaterial—Override the pass material entirely.

Spread vs Blur. Spread grows the silhouette before the blur, so the shadow gets bigger while staying equally sharp. Blur softens without growing. A tight, deep shadow is high spread with low blur; an ambient occlusion look is low spread with high blur.

Glow

LcGlow radiates colour outward from the silhouette. Add it: Add Component → Lucent UI → Effects → Lc Glow, or GameObject → Lucent UI → Effects → Glowing Card.

using Lucent.Effects;

var glow = go.AddComponent<LcGlow>();

glow.Spec.Color     = new Color32(64, 224, 255, 255);
glow.Spec.Radius    = 16f;
glow.Spec.Intensity = 1f;
glow.Spec.Blend     = LcBlendMode.Additive;   // true light-adding bloom
LcGlowEffectDefaultMeaning
ColorcyanGlow colour.
ColorToken""Theme token override.
Radius12Outward reach in pixels.
Intensity1Strength multiplier on the edge alpha.
BlendNormalAdditive gives a real bloom.
PerSidefalseUse SideWidths instead of one uniform radius.
SideWidthsuniform 12LcSideWidths — Top, Right, Bottom, Left.

Per-side glow

glow.Spec.PerSide    = true;
glow.Spec.SideWidths = new LcSideWidths(top: 24f, right: 4f, bottom: 4f, left: 4f);

var even = LcSideWidths.Uniform(12f);
bool any = even.AnyPositive;

Per-side reach is how you suggest a light source above a control, or emphasise the leading edge of a selected item, without rotating anything.

Presets and pulsing

LcGlowPresetId provides four named looks: Soft, Neon, Ember and Aura (plus None). LcGlowPulse animates a glow — add it for a breathing highlight on a focused or "new" element.

Add Component → Lucent UI → Effects → Lc Glow Pulse

Reusable looks can be saved as assets: Assets → Create → Lucent UI → Effects → Glow Style, or … → Animated Glow Preset for the animated form.

Outline

LcOutline strokes the silhouette. Unlike Unity's built-in Outline, which offsets duplicate copies of the mesh, this follows the real outline at a true width.

using Lucent.Effects;
using Lucent.Render;

var outline = go.AddComponent<LcOutline>();

outline.Spec.Color  = Color.white;
outline.Spec.Width  = 2f;
outline.Spec.Align  = LcStrokeAlign.Inner;   // Inner | Center | Outer
outline.Spec.OnTop  = true;                  // paint above any glow
LcOutlineEffectDefaultMeaning
Color / ColorTokenwhiteStroke colour, or a theme token.
Width2Thickness in pixels.
AlignCenterInner keeps the footprint; Outer grows it.
OnToptruePaint in the Overlay layer (above glow) rather than the Stroke layer.
BlendNormalCompositing mode.

For a focus ring, Inner alignment is usually correct — the element keeps its exact layout footprint whether or not it is focused, so nothing reflows when focus moves.

Neumorphism & Inner Shadow

Neumorphism

LcNeumorphism casts the paired light and dark shadows of the soft-UI style in a single pass. Add it: Add Component → Lucent UI → Effects → Lc Neumorphism.

var neu = go.AddComponent<LcNeumorphism>();

neu.Spec.LightColor = new Color32(255, 255, 255, 140);
neu.Spec.DarkColor  = new Color32(0, 0, 0, 120);
neu.Spec.Offset     = new Vector2(6f, -6f);   // dark shadow; light mirrors it
neu.Spec.Blur       = 10f;
neu.Spec.Spread     = 0f;

Offset is the cast for the dark shadow; the light shadow is mirrored automatically, so the pair stays consistent and you only set one direction.

Accessibility. Neumorphism works by very low contrast between an element and its background — which is precisely what WCAG contrast minimums forbid. If you use it for interactive controls, carry the affordance in something else too: a border, a label, or a focus outline. Lumina Theme ships LcContrast for checking this.

Inner shadow

LcInnerShadow casts depth inward from the edge — the pressed, inset or recessed look.

var inner = go.AddComponent<LcInnerShadow>();

inner.Spec.Color  = new Color32(0, 0, 0, 102);
inner.Spec.Offset = new Vector2(0f, -4f);   // direction the light comes FROM
inner.Spec.Blur   = 8f;

GameObject → Lucent UI → Effects → Pressed Panel creates one configured. Note that inner shadow renders in the Overlay layer, above the fill — that is what makes it read as inset rather than as a shadow behind the element.

Stacking & Layers

Effects compose. Each declares the layer it paints into, and the layers always composite in a fixed order — so a shadow can never accidentally land on top of a fill.

LcDrawLayerOrderEffects that target it
Shadow0 (back)LcDropShadowEffect, LcNeumorphismEffect
Fill1The element itself
Stroke2LcOutlineEffect when OnTop is false
Glow3LcGlowEffect
Overlay4 (front)LcInnerShadowEffect, LcOutlineEffect when OnTop is true

Blend modes

LcBlendModeUse for
NormalDefault. Batches into the host mesh.
AdditiveTrue light-adding glow / bloom.
ScreenSofter lightening than additive.
MultiplyDarkening passes.

Normal is the only mode that batches into the host mesh; the others need their own pass. Prefer Normal unless the look genuinely requires light addition.

LcGraphicEffect is the bridge for existing UI: point it at a stock Image or Text and it derives a silhouette through LcSpriteSilhouette, so you can shadow or glow UI you did not author with this package.

Writing a custom effect

Implement ILcEffect: declare a stable LcTypeId, a TargetLayer, whether you need the backbuffer, and an Apply(LcEffectContext). Your effect then stacks with the built-in ones under the same rules.

Theme Tokens

Every colour-bearing effect accepts a ColorToken alongside its literal Color. When a theme is bound, the token wins — so a theme switch restyles shadows, glows and outlines along with everything else.

using Lucent.Theme;

glow.Spec.ColorToken   = LcColorKeys.Accent;
shadow.Spec.ColorToken = LcColorKeys.Border;

Leave ColorToken empty (the default) to use the literal colour. The theme runtime is bundled with this pack; the Theme Designer, palette import and WCAG helpers are part of Lumina Theme.

Built-in RP Fallback

Under the Built-in render pipeline the blur runs through a CommandBuffer path instead of a URP renderer feature. It is provided so a Built-in project is not locked out of frosted panels.

TypeRole
LcBlurBuiltInManagerOwns the Built-in blur lifecycle.
LcBlurCommandBufferThe CommandBuffer grab-and-blur path.
LcBlurFeatureThe URP renderer feature (installed by the Tools menu command).
LcBlurManagerPipeline-neutral entry point used by panels.
LcBlurPingPong, LcBlurRequestPing-pong targets and the per-panel request.

LcCapabilities.BuiltInSceneColorGrabActive reports whether the grab is currently running, and SupportsSceneColorGrab is the single flag both paths answer through — which is what LcBlurPanel.IsSupported reads. Write your fallback against IsSupported, not against a pipeline check, and it stays correct on every target.

Performance

Blur is the expensive part

Geometry effects — shadow, glow, outline, neumorphism, inner shadow — are mesh work and cost roughly what an extra graphic costs. Blur and glass sample the backbuffer and cost real GPU time that scales with Radius and Quality.

  • Prefer fewer, larger blur panels to many small ones — each is a separate grab.
  • Drop Quality before dropping Radius on mobile; quality is much cheaper to lose than the look.
  • Use Grain instead of Ultra when the artefact you are fighting is banding rather than blockiness.
  • BlurUiBehind costs extra — leave it off unless you genuinely need UI behind the panel blurred.
  • Keep Blend at Normal where possible; it is the mode that batches into the host mesh.

Caching

LcShadowCache reuses blurred silhouettes across frames, and effects invalidate against ILcSilhouetteSource.SilhouetteVersion — so a static shadow is generated once and a shadow only rebuilds when the shape underneath actually changes. An element that animates position but not shape does not regenerate its shadow.

FAQ & Troubleshooting

My blur panel renders flat / does nothing.

Under URP, run Tools → Lucent UI → Install Blur Renderer Feature. Then check panel.IsSupported at runtime. If it is true in the editor but false in a build, the blur shader was stripped — keep it under Resources or add it to Always Included Shaders.

It works in the editor but not in WebGL.

Almost always shader stripping. See above. Confirm the shader is in the build, then re-check.

Can I use blur with HDRP?

No. The HDRP blur variant is deliberately excluded so the package does not force an HDRP dependency on URP-only projects. The geometry effects work fine under HDRP.

The glass looks like plastic.

Raise Gloss and EdgeGlint, and give it a real BevelWidth. Flat glass with no bevel has no edge to catch light, which is what reads as plastic. Then confirm LightAngle matches your other panels.

Text behind the glass is unreadable.

Lower Refraction. Values above roughly 0.05 distort enough to hurt legibility. ChromaticAberration compounds it — keep it around 0.01.

My shadow is a rectangle, not the shape.

The effect needs a silhouette source. Lucent shapes provide one natively; for a stock uGUI Image, use LcGraphicEffect, which derives the silhouette from the sprite.

Shadow gets bigger when I increase blur.

Blur softens outward from the edge, so a large blur reads as a bigger shadow. If you want size without softness, use Spread.

Glow is washed out.

Set Blend to Additive. Normal blending composites over the backdrop; additive adds light, which is what a glow physically does.

How many blur panels can I have on screen?

It depends on radius, quality and GPU. Profile on your lowest target. If several panels are adjacent, one larger panel is usually both cheaper and better-looking than several small ones.

Does this need Lumina Shapes?

No. The shape generators this pack needs are bundled. Lumina Shapes adds the full shape authoring tooling — style presets, the shape inspector, silhouette masking.
