Lumina Glass UI

Liquid glass, background blur & procedural UI effects for Unity uGUI.

Unity 6000.0.62f1+URPuGUI 100% proceduralIL2CPP / WebGL

1. Overview

Lumina Glass UI renders real-time liquid glass, background blur, drop shadow, glow, outline and pressed-panel effects directly on uGUI elements. Everything is procedural — no sprites, no .mat files — so it stays crisp at any resolution and composes into a single mesh per element. The blur-behind and liquid-glass effects use a URP renderer feature that installs itself automatically; a Built-in Render Pipeline CommandBuffer fallback is also included.

2. Requirements

  • Unity 6000.0.62f1 or newer.
  • Universal Render Pipeline (URP) for blur / liquid glass — package com.unity.render-pipelines.universal. (Built-in RP works via the CommandBuffer fallback.)
  • com.unity.ugui — present in every Unity project.

3. Installation

  1. Import Lumina Glass UI.unitypackage (Assets ▸ Import Package ▸ Custom Package…).
  2. On first import the URP blur renderer feature is auto-installed. You can re-run it any time:
Tools ▸ Lucent UI ▸ Install Blur Renderer Feature
The installer is idempotent — running it twice never adds a duplicate feature. It edits the active URP renderer exactly the way Unity's own “+ Add Renderer Feature” button does.

4. Quick start

  1. Create an effect from the menu (a Canvas + EventSystem are created automatically if absent):
GameObject ▸ Lucent UI ▸ Effects ▸ Liquid Glass Card
  1. Place a colorful image or 3D scene behind the card in the hierarchy.
  2. Press Play — the background is blurred and refracted through the glass in real time.
If the blur looks like a flat tint, run Tools ▸ Lucent UI ▸ Install Blur Renderer Feature once, then re-enter Play. This means the URP renderer feature wasn’t registered yet.

5. Effects reference

Each menu item drops a pre-configured LcShape with the matching effect component(s).

Menu (GameObject ▸ Lucent UI ▸ Effects ▸ …)ComponentKey spec fields
Shadowed PanelLcShadowSpec.Color, Offset, Blur, Spread
Glowing CardLcGlowSpec.Color, Radius, Intensity
Outlined ShapeLcOutlineSpec.Color, Width, Align, OnTop
Pressed PanelLcInnerShadowSpec.Color, Offset, Blur
Blur PanelLcBlurPanelSpec.Quality, CornerRadius, Tint
Liquid Glass CardLcGlassSpec (+ Squircle, Vibrancy), GlassSpec.NativeShadow

To add an effect manually: put an LcShape on a Canvas child, then Add Component and type the effect name (e.g. Lc Glow). Blur/glass panels also want an LcBlurManager in the scene — it is auto-created at runtime, or add one for an authored scene.

6. Scripting

Add a soft shadow in code

using Lucent.Shapes;
using Lucent.Effects;
using Lucent.Render;
using UnityEngine;

var go = new GameObject("Card", typeof(RectTransform));
go.transform.SetParent(canvas.transform, false);

var shape = go.AddComponent<LcShape>();
shape.ShapeKind = LcShapeKind.RoundedRect;
shape.SetUniformRadius(20f);
shape.SetFillColor(new Color32(24, 28, 36, 255));

var shadow = go.AddComponent<LcShadow>();
shadow.Spec.Color  = new Color32(0, 0, 0, 110);
shadow.Spec.Offset = new Vector2(0f, -8f);
shadow.Spec.Blur   = 16f;
shadow.Spec.Spread = 1f;

Configure a liquid-glass card

var glass = go.AddComponent<LcGlass>();

var spec = LcBlurPanelSpec.CreateDefault();
spec.Quality             = LcBlurQuality.High;
spec.Squircle            = true;
spec.SuperellipseExponent= 4f;
spec.CornerRadius        = 28f;
spec.Vibrancy            = 1.25f;
spec.Tint                = new Color32(255, 255, 255, 26);
glass.Spec = spec;

var gspec = LcGlassSpec.CreateDefault();
gspec.NativeShadow = true;
glass.GlassSpec = gspec;

7. Troubleshooting

SymptomFix
Blur shows a flat tint, no blurRun Tools ▸ Lucent UI ▸ Install Blur Renderer Feature; confirm the project uses URP.
Effect invisible in a buildShaders live under Runtime/Shaders/Resources and are Resources-referenced so they survive stripping — keep that folder intact.
Nothing rendersThe element must be under a Canvas. Use the GameObject menu (it wires the Canvas for you).
