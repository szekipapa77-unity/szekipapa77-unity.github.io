Lumina Layout

Safe Area & responsive scaling for Unity uGUI.

Unity 6000.0.62f1+uGUI Any render pipelineTestable providers

1. Overview

Lumina Layout gives you two dependable building blocks for UI that fits every screen: a Safe Area fitter that insets content away from notches, rounded corners and home indicators, and a Responsive Scaler that rescales your UI by width/height breakpoints. Both use injectable providers so they’re unit-testable and simulator-friendly. The pack also bundles the layout math helpers LcAutoSize, LcFlexLayout and LcLayoutMath.

2. Requirements

  • Unity 6000.0.62f1 or newer.
  • com.unity.ugui — present in every Unity project.
  • No render-pipeline dependency.

3. Safe Area

Quick start

  1. Select a full-screen UI panel and add the component:
Add Component ▸ Lucent UI ▸ Layout ▸ Lc Safe Area
  1. In the Game view, choose a notched device (or open the Device Simulator).
  2. The panel insets on the enabled edges. Toggle edges per-side in the Inspector.

API

MemberPurpose
ApplyLeft / ApplyRight / ApplyTop / ApplyBottomPer-edge inset toggles (properties; re-apply on change).
Apply()Force a re-fit (e.g. after a manual orientation change).
using Lucent.Layout;

var safe = panel.AddComponent<LcSafeArea>();
safe.ApplyTop = true;
safe.ApplyBottom = true;
safe.Apply();
Safe Area accepts injectable safe-area & screen-size providers, so you can drive it from tests or a custom device profile instead of the live Screen.safeArea.

4. Responsive Scaler

Quick start

Add Component ▸ Lucent/Layout ▸ Lc Responsive Scaler

Set your Reference Resolution and base metrics; resize the Game view and the UI rescales.

API

MemberPurpose
ReferenceResolution, MatchWidthOrHeightDesign resolution & match axis.
BaseFontSize / BasePadding / BaseBorder / BaseSpacingBase metrics to scale from.
CurrentScale, ActiveBreakpointCurrent computed scale & breakpoint index.
ScaledFontSize / ScaledPadding / …Convenience scaled values.
Scale(float baseValue)Scale any value by the current factor.
Refresh()Recompute now (after a resolution change).
using Lucent.Layout;

var scaler = GetComponent<LcResponsiveScaler>();
scaler.ReferenceResolution = new UnityEngine.Vector2(1920f, 1080f);
scaler.BaseFontSize = 32f;

float fontPx = scaler.ScaledFontSize;      // 32 * CurrentScale
float pad    = scaler.Scale(16f);          // any value, scaled

5. Layout math helpers

  • LcAutoSize — SetSize, FitContent, ApplyAspect (aspect-lock a RectTransform to content or a ratio).
  • LcFlexLayout — weighted flex distribution along an axis with per-item margins.
  • LcLayoutMath — ResolveScale, SelectBreakpoint, screen-metric utils.

6. Troubleshooting

SymptomFix
Safe Area doesn’t insetThe device must report a non-full Screen.safeArea; use a notched preset or the Device Simulator. Ensure the panel is full-screen (stretch anchors).
Scaler not updatingCall Refresh() after changing the resolution at runtime.
