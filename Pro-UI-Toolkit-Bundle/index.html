Five production tools

Pro UI & Data Toolkit - 5 Asset Bundle. Each tool is a complete product that is also sold on its own; nothing here is a trimmed-down edition.

Getting started

  1. Import the package. Every tool lands in its own folder under Assets.
  2. Open Tools ▸ Toolkit Pack ▸ Welcome. It lists the tools that are present, opens each one, opens its documentation, and warns if a required Unity package is missing.
  3. Open any tool's own Documentation.html for its full reference.

The welcome window also appears once per project on first import.

What is included

Helix Vizforge

Charts, dashboards and data visualization. Lines, areas, splines, bars, stacks, waterfalls, radial and statistical views, composed into dashboards for uGUI, UI Toolkit or world space.

Docs: Assets/Helix/Documentation/Documentation.html

VeloScroll

Infinite recycling ScrollView for uGUI. Lists, grids, tables and dashboards at 100,000+ rows with recycled cells, no-code setup, CSV/JSON import and sticky sections.

Docs: Assets/VeloScroll/Documentation/Documentation.html

TypeFlow Pro

Animated RTL and Arabic text for TextMeshPro. Correct Arabic shaping and bidirectional layout, plus typewriter and reveal animations that respect it.

Docs: Assets/TypeFlowPro/Documentation/Documentation.html

Universal Asset Preview Studio

Thumbnails, catalogs and asset QA. Browse the project, capture thumbnails, validate quality, compare dependencies and export catalogs from one editor window. Editor-only.

Docs: Assets/UniversalAssetPreviewStudio/Documentation/Documentation.html

Astra Web Platform

Embedded WebView, JS bridge and OAuth. Web views inside Unity with a JavaScript bridge, OAuth/OIDC sign-in, profiles, policies and diagnostics. Check its documentation for the per-platform WebView matrix.

Docs: Assets/AstraWebPlatform/Documentation/Documentation.html

Removing a tool you do not need

Delete its folder under Assets. The five tools do not reference each other, and the Toolkit Pack window resolves them by name rather than by assembly reference, so nothing else breaks and the project keeps compiling.

Requirements

Unity6000.0 or newer
Render pipelinesBuilt-in, URP and HDRP - none of the five draws pipeline-specific scene content
Required packagecom.unity.ugui (TextMeshPro), used by TypeFlow Pro and VeloScroll
Optional packagescom.unity.inputsystem, com.unity.burst, com.unity.collections, com.unity.mathematics - detected automatically and used only where present
