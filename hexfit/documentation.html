CHAPTER 01

Start here: Hex Fit

Hex Fit is a standalone editable Unity game template. Drag a comb from the tray onto empty honeycomb cells. Fill complete lines along the hex board axes to clear them. Meet the level goal before the comb budget runs out. Some boards contain flowers, bees, wax or holes; inspect the displayed goal. Meadow endless mode unlocks at level 5 and has separate high-score play.

Includes 25 curated levels, level generation, a game-specific visual editor and validation, 4 guided helpers, local saving and portrait/landscape scenes. Keep the required private game Kit and publisher-owned Szekipapa77Ads layer. Provider SDK binaries are excluded. There is no bundled HLK, purchases, multiplayer server or remote LiveOps backend. Import only one game Kit into a project because the Kit classes share names.

CHAPTER 02

Requirements, installation and first play

Use Unity 6000.0.62f1, URP 17.0.4 and Unity UI 2.0.0. Install matching Android SDK/NDK/OpenJDK and WebGL modules in Unity Hub. Retain the supplied manifest and ProjectSettings.

  1. Extract the standalone project to a short writable local path, then open it in the matching editor. Wait for package import and compilation.
  2. For native unitypackage import, create a matching URP project and use Assets > Import Package > Custom Package. Import every game, Kit, Szekipapa77Ads and WebGL-template entry.
  3. Run Szekipapa77 > Hex Fit > Setup. It configures rendering and player settings; review its changes when integrating with existing work.
  4. Active Input Handling must support the classic Input Manager: choose Old or Both. New Input System only is insufficient.
  5. Open Assets/Games/HexFit/Scenes/HexFit_Mobile.unity and press Play. Follow the level card and first-level instructions.
  6. Stop Play mode before editing level assets. Keep all .meta GUIDs. The game uses classic Unity UI Text; do not assume an extra TextMesh Pro import is required.

CHAPTER 04

Gameplay, controls and progression

Drag a comb from the tray onto empty honeycomb cells. Fill complete lines along the hex board axes to clear them. Meet the level goal before the comb budget runs out. Some boards contain flowers, bees, wax or holes; inspect the displayed goal. Meadow endless mode unlocks at level 5 and has separate high-score play.

The initial bank has 25 curated levels. Read the supplied loader/generator before changing continuation rules. Play the guided opening, ordinary progress, completion and retry paths; preserve saved indexes during a visual reskin. The Mobile scene is portrait and the WebGL-named scene is landscape, but the supplied Build menu selects portrait for both build targets. Select landscape explicitly in your Build Profile if desired. Test a near-startup scene replacement as well as a normal restart.

CHAPTER 05

Tutorials and every helper

Fresh local progress triggers the first-level guidance. Newly unlocked helpers have introduction and guided-use flows. Reset only a test save when reviewing tutorials. A free guided first use can differ from ordinary charge consumption. BoostName, BoostShort, BoostUnlock and BoostStart in HexFitGame.cs; BoostDesc and guide strings in HexFitGame.Hud.cs.

HelperUnlockFree chargesAction and effect
Spin33Arm Spin and tap a nonsymmetric multi-cell tray comb to rotate it 60 degrees.
Smoker62Arm Smoker and tap the hive to clear that cell and its six neighbors; eligible flowers/bees count.
Fresh Combs102Deals the next fresh tray pieces.
Drip152Arm Drip and tap a multi-cell tray comb to turn it into a single drop.

Activate the tool and perform its required target action: arming a tool alone does not demonstrate its effect. Undo needs an eligible previous move, Scoop needs sand, Spin needs a nonsymmetric comb and Drip needs a multi-cell comb. Exhausted charges may offer a rewarded ad; verify success/cancel/failure and grant a reward once only.

CHAPTER 06

Visual level editor: worked editing session

Open Szekipapa77 > Hex Fit > Level Editor. Exact implementation: Editor/HexFitLevelEditor.cs.

Duplicate an early board. Set Name, First-time hint, Goal and target, Comb budget, Breather, Deal difficulty and Seed. Opening combs stores explicit shape/turn codes; Clear queue removes that fixed opening. Hive radius and shape affect board geometry; Apply shape replaces the layout. Left-drag paints, right-click empties a cell. Set flowers/bees/wax/holes deliberately. Calibrate measures a suitable target/budget with the bot. Validate and Save before Play this level.

  1. Back up Resources/hexfit/Levels/levels.json.
  2. Duplicate a simple early level and edit one small element.
  3. Use the game-specific validation controls and resolve every reported issue.
  4. Save explicitly; stop and restart Play mode, then use Play this level or navigate to the edited index.
  5. Check portrait and landscape and rebuild demo outputs after accepting data changes.

CHAPTER 07

Generator, insertion and replacement

Count 1–100; Start at level #; Seed; Start/End difficulty; Breather every 0–8; Replace that range (else insert). Checked replaces existing records in the range; unchecked inserts and shifts subsequent records. Start 26 appends. HfGen uses validation/bot measurements; inspect solvable, botRate, botPieces and score in saved level data and manually test the result.

Worked extension: back up the bank, generate five candidates after the original 25 at moderate difficulty, validate them, then Save. Reopen the JSON and confirm the count changed. An unchecked replace option inserts rather than silently destroying later data. Runtime continuation does not automatically append new records to project JSON. Validation and bot scores help find problems but do not certify a pleasant human difficulty curve.

CHAPTER 11

Artwork, fonts, audio and licences

Replace game images under Resources/hexfit through Unity while retaining resource keys, .meta GUIDs, Sprite/UI import settings, alpha, pivots and slicing. Procedural graphics in the art/view sources may need separate colour changes. Replacing one PNG does not change every fallback. Keep third-party font and other licence notices with the corresponding shipped assets.

Music is Resources/hexfit/Music/meadow_loop.ogg. Preserve its load key when replacing it, check loop boundaries/compression and test Sound and Music toggles separately. Kit UI uses supplied fonts; validate glyph coverage for new languages and retain the actual font licence files.

CHAPTER 12

Local saves, reset and migration

HzSave wraps PlayerPrefs and flushes local state on focus loss/quit. WebGL persistence uses browser storage tied to the hosting origin. Clearing site data or changing origin starts a new local save; this is not cloud synchronization. Inspect HzSave/PlayerPrefs calls in the actual game source before altering progression, stars, helper charges or tutorial flags.

Verify fresh launch, a completed puzzle, helper use, sound options, focus loss and restart. Use a dedicated test profile for resets. Keep technical save keys stable during colour/text reskins. If changing schema or keys, implement and test a migration rather than silently discarding existing users’ progress.

CHAPTER 13

Advertising integration and configuration

Asset: Assets/Szekipapa77Ads/Resources/AdsSettings.asset. Inspect backend, useGoogleTestIds and missingSdkFallback in the publisher-owned Ads configuration. Buyer projects include adapter/integration code and exclude external provider SDK binaries. WebGL and a missing-provider fallback simulate ads; these are not live commercial impressions.

For real Android ads install the supported provider SDK from its official source into your working project, enter your own app/placement IDs and use test ads first. Verify banner/interstitial/rewarded callbacks on supported hardware. For production use your own IDs and disable simulated missing-SDK fallback. Build tooling rejects unsafe production fallback settings. No IAP, remote backend or HLK is included in this publisher edition.

CHAPTER 14

Android build and release

Install Unity 6000.0.62f1 Android modules through Hub. Select Android, run Setup and review application ID com.szekipapa77.hexfit, version, scene orientation and signing. The build command writes Builds/Android/hexfit.apk. Confirm BuildResult.Succeeded and the actual output file; intermediate report totals are not the final APK size.

Use your own keystore/signing and distribution settings. A test-signed demo is not a signed store release. A provider-free build simulates ads; a provider test-demo does not prove production ad-account configuration. Test real hardware touch, safe areas, focus/audio, save/relaunch and reward callbacks. Keep passwords, keystores and private service credentials out of buyer packages.

CHAPTER 15

WebGL build and hosting

Install matching WebGL support. Run Setup and Build WebGL; output is Builds/WebGL/hexfit/. Serve index.html with all loader/framework/data/WASM/StreamingAssets files over HTTP(S), not file://. Match compression, Content-Encoding and MIME types to the host. Outer page sizing and actual scene orientation are different settings.

The publisher’s playable demo is hosted on HyperCodeStore. Upload the actual runtime files rather than merely changing a URL. Test a fresh anonymous load, real pointer controls, audio after interaction, saved progress/reload and phone/desktop sizing. Rebuild and rehost when code/assets change. A successful HTTP page alone is not gameplay verification.

CHAPTER 16

Troubleshooting

Compile errors: restore matching packages and the full private Kit/Ads layer; only one game Kit belongs in a project. Pink/invisible rendering: run Setup and inspect Graphics and every Quality URP assignment. No input: classic input handling must be enabled; check canvas focus and blocking modals. Missing resources: restore exact paths, .meta GUIDs and importer settings.

Edits do not appear: stop Play, Save in the level editor, reload the canonical bank and check current saved level. Text reverts: update construction and refresh assignments from the exact table. No live ads: provider binaries are deliberately excluded; inspect your installed provider and fallback mode. Scene reload exception: retain owner-lifetime and generation guards on delayed callbacks. WebGL fails: inspect browser Console, compression headers and missing payloads.
