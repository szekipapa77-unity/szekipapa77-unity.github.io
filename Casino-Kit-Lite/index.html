Casino Kit Lite

Two complete casino games - Blackjack and a Classic 3-Reel Slot - on the real shared engine: one wallet, one lobby, one betting UI, one save file, authored portrait and landscape layouts, and editable payout assets. This is the free edition of Complete Casino Kit.

Getting started

  1. Import the package. Everything lands under Assets/CompleteCasinoKit.
  2. Add these three scenes to File > Build Profiles > Scene List, in this order: Scenes/Lobby.unity, Games/Cards/Blackjack/Scenes/Table_Blackjack.unity, Games/Slots/Classic3Reel/Scenes/Table_Classic3Reel.unity. The lobby loads the game scenes additively by name, so they have to be in the list.
  3. Open Scenes/Lobby.unity and press Play. Pick a game from the grid; Esc or the gamepad's east button returns you to the lobby.

Each game scene also runs on its own, without the lobby - open Table_Blackjack.unity and press Play. That is how the included play-mode smoke tests exercise them, and it is the quickest way to iterate on one table.

Editing the payouts

Both games read a ScriptableObject, so a designer can retune them without touching code. Select Config/Classic3Config.asset or Config/BlackjackConfig.asset and edit in the inspector - the custom editors group the fields and validate the numbers.

From code

// the same rules the tables use, callable on their own
var shoe = new Shoe(deckCount: 6);
shoe.Shuffle(new Xoshiro128SS(seed: 12345));
var player = new List<Card> { shoe.Deal(), shoe.Deal() };
BlackjackTotal total = HandTotals.Blackjack(player);
Debug.Log(total + (total.IsBlackjack ? " - blackjack" : ""));

// exact slot maths for the authored reel set, with no spinning required
SlotCycleResult cycle = classic3Config.ComputeExactReturn();
Debug.Log($"RTP {cycle.Rtp:P2}, hit frequency {cycle.HitFrequency:P2}, "
        + $"max win x{cycle.MaxWinMultiple:0.#} over {cycle.Combinations:N0} combinations");

Known limits

  • The wallet is a local simulation. There is no real-money play, no server, and no IAP billing - the shop is a full-edition feature and is simulated there too.
  • Saves are local and signed against casual tampering, not against a determined attacker. Move to a backend for anything competitive.
  • Audio is synthesised, not recorded. It is production-usable and royalty-free, but it is not a licensed music bed.

Third-party content

This package contains no third-party fonts, images, audio, icons, shaders, DLLs or native binaries, and makes no runtime network requests. Some of the runtime art is AI-assisted and is enumerated file by file in Third-Party Notices.txt in the package root - please read that file for the full disclosure.
