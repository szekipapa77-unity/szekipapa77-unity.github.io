CHAPTER 01

Start here: Squire's Ascent

Squire's Ascent is a standalone editable Unity game template. Time advances while your selected job pays crowns and gains experience. Train a skill alongside the job, select newly opened careers and manage housing and goods. Follow chapter goals and the supplied Ages progression; all progression is local.

Includes 25 curated chapters, source-backed generation, a game-specific visual editor and validation, 4 guided helpers, local saving and portrait/landscape scenes. Keep the required private game Kit and publisher-owned Szekipapa77Ads layer. Provider SDK binaries are excluded. There is no bundled HLK, purchases, multiplayer server or remote LiveOps backend. Additional included libraries: 9 categories, 20 jobs, 17 skills, 16 items, 4 boosters, 4 seasons. Import only one game Kit into a project because the Kit classes share names.

CHAPTER 02

Requirements, installation and first play

Use Unity 6000.0.62f1, URP 17.0.4 and Unity UI 2.0.0. Install matching Android SDK/NDK/OpenJDK and WebGL modules in Unity Hub. Retain the supplied manifest and ProjectSettings.

  1. Extract the standalone project to a short writable local path, then open it in the matching editor. Wait for package import and compilation.
  2. For native unitypackage import, create a matching URP project and use Assets > Import Package > Custom Package. Import every game, Kit, Szekipapa77Ads and WebGL-template entry.
  3. Run Szekipapa77 > Squire's Ascent > Setup. It configures rendering and player settings; review its changes when integrating with existing work.
  4. Active Input Handling must support the classic Input Manager: choose Old or Both. New Input System only is insufficient.
  5. Open Assets/Games/SquireAscent/Scenes/SquireAscent_Mobile.unity and press Play. Follow the level card and first-level instructions.
  6. Stop Play mode before editing level assets. Keep all .meta GUIDs. The game uses classic Unity UI Text; do not assume an extra TextMesh Pro import is required.

CHAPTER 04

Gameplay, controls and progression

Time advances while your selected job pays crowns and gains experience. Train a skill alongside the job, select newly opened careers and manage housing and goods. Follow chapter goals and the supplied Ages progression; all progression is local.

The initial bank has 25 curated chapters. Read the supplied loader/generator before changing continuation rules. Play the guided opening, ordinary progress, completion and retry paths; preserve saved indexes during a visual reskin. The Mobile scene is portrait and the WebGL-named scene is landscape, but the supplied Build menu selects portrait for both build targets. Select landscape explicitly in your Build Profile if desired. Test a near-startup scene replacement as well as a normal restart.

WebGL fails: inspect browser Console, compression headers and missing payloads.
