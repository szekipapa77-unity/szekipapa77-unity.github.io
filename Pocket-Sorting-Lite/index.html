Pocket Sorting Lite

One complete ball-sort puzzle - Marble Grove - on the full suite's engine: three boosters, a coin wallet, a level menu, stars, saved runs and a responsive UI. Free edition of Pocket Sorting Games, with no ads anywhere.

Getting started

  1. Import the package. Everything lands under Assets/PocketSortingGames.
  2. Open Games/MarbleGrove/Scenes/MarbleGrove.unity and press Play.
  3. Add that scene to File > Build Profiles > Scene List before you build.

There are no ads in this package. The full edition's AdMob integration, the rewarded ad UI and the consent flow are not here - the scripts are absent, not switched off, so the build makes no ad network calls and needs no SDK.

The game

Marble Grove - move marbles between tubes until each tube holds one colour. Only a matching marble (or an empty tube) will take a move, and every board is solvable within its move limit.

LevelsTwo authored boards, each a SortLevel asset with its own layout and move limit.
BoostersUndo, Extra Tube and Hint, with charges and a 60-coin top-up.
SolverSortingModel is pure logic: it validates a move, detects a dead end and finds the hint. The editor's validator replays every shipped board to prove it is solvable.
StarsUp to three per board, from moves used against the limit.
SavesA run in progress, your coins, charges and stars persist between sessions.
ThemeMidnight Arcade - neon edges, arcade metal, night skies.

Authoring a board

A board is a SortLevel asset: the tube count, how many marbles of each colour, and a move limit. Duplicate Games/MarbleGrove/Levels/Level01.asset, edit it, and add it to the levels array on the MarbleGrove prefab. Then run Window > Pocket Sorting > Validate every level solution to confirm it can be finished.

What the full edition adds

The features below are not implemented in this package: the other games have no scenes, prefabs, level assets, art or audio here, and the extra themes have no atlases. There is no hidden flag that unlocks them. The controls that lead to them stay in place, so you can see the shape of the finished product; pressing one says which edition provides it.

  • Four more games - Color Lab and Garden Pour (liquid sorting), Mood Tubes (emoji tubes) and Shelf Party (shelf matching), each on this same engine.
  • Ten more boards for this game, and sixty across the five.
  • 24 more themes - an atlas, backdrop, font and palette per theme.
  • Device haptics - the native plugin, the haptic pattern assets and the settings that drive them.
  • Rewarded ads - the AdMob integration and the consent flow.

Known limits

  • Two boards. The remaining ten for this game are full-edition content.
  • One theme. The theme button explains where the others are.
  • Saves are PlayerPrefs, which is per-device and not authoritative.
  • Lite and the full edition install to the same folder and share asset GUIDs. If you upgrade later, delete Assets/PocketSortingGames before importing the full edition.

Third-party content

Two OFL fonts (Nunito and Rajdhani) ship with their OFL.txt files next to them. Ten runtime PNGs are AI-assisted and are listed by name in Third-Party Notices.txt in the package root; the audio is synthesised in code. Please read that file for the full disclosure.
