Lumina Shapes

Procedural, resolution-independent vector shapes for Unity uGUI.

Unity 6000.0.62f1+uGUI Any render pipelineNo sprites · no materials

1. Overview

Lumina Shapes draws crisp, anti-aliased shapes that are tessellated at runtime and re-mesh live as you edit them. Because they are procedural — no textures, no atlases, no .mat files — they stay razor-sharp at any scale and DPI. One shape is one mesh, one draw call.

2. Requirements

  • Unity 6000.0.62f1 or newer.
  • com.unity.ugui — present in every Unity project.
  • Render-pipeline agnostic (ships its own procedural canvas shader). URP recommended.

3. Quick start

GameObject ▸ Lucent UI ▸ Rounded Panel
  1. Create the shape from the menu (a Canvas + EventSystem are created automatically if absent).
  2. In the Inspector, change Shape Kind and the corner radius — the mesh re-tessellates instantly, even outside Play mode.

4. Create menu

Menu (GameObject ▸ Lucent UI ▸ …)Result

Rounded PanelRounded-rect surface — the “card” primitive.
CircleAnti-aliased disc.
Pill (Capsule)Fully-rounded capsule that stays correct at any size.

Add to your own object with Add Component ▸ Lucent UI ▸ Lc Shape (place it under a Canvas).

5. Shape kinds & styling

Set ShapeKind (Lucent.Render.LcShapeKind) to any of rounded-rect, circle, pill/capsule, triangle, regular polygon (via SetSides), hexagon, star, ring/arc, chevron and more. Fill, per-corner radii, stroke and gradients are all first-class.

Author a look once and reuse it: Assets ▸ Create ▸ Lucent UI ▸ Shape Style Preset. The preset’s inspector has an Apply button that pushes the style onto any selected shapes.

6. Scripting

Build a shape in code

using Lucent.Shapes;
using Lucent.Render;
using UnityEngine;

var go = new GameObject("Panel", typeof(RectTransform));
go.transform.SetParent(canvas.transform, false);

var shape = go.AddComponent<LcShape>();
shape.ShapeKind = LcShapeKind.RoundedRect;
shape.SetUniformRadius(24f);
shape.SetFillColor(new Color32(32, 36, 44, 255));
shape.SetStroke(true, 3f);
shape.SetStrokeGradient(true, new Color32(120,200,255,255),
                              new Color32(180,120,255,255), 45f);

7. Troubleshooting

SymptomFix
Shape doesn’t appearIt must be under a Canvas; the GameObject menu wires one for you.
Missing in a build (pink/blank)Keep Runtime/Shaders/Resources intact — the procedural canvas shader is Resources-referenced so it survives stripping.
Edits don’t update the meshCall RebuildFromInspector() after bulk API changes, or toggle the component.
