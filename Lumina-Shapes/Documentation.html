Lumina Shapes Unity 6000.0.62f1+

Twelve resolution-independent uGUI shapes with real strokes, gradients, patterns and silhouette masking — no sprite atlas required.

Overview

Lumina Shapes replaces the sliced-sprite workflow for UI geometry. Instead of authoring a 9-slice PNG for every corner radius and every colour, you drop one LcShape component and set the radius as a number. Geometry is generated procedurally and anti-aliased analytically, so a shape stays crisp at any resolution and any scale.

  • 12 shape kinds — rounded rect, circle, ellipse, polygon, star, chamfer, parallelogram, path, arc, pie, ring and capsule.
  • Four fill kinds — solid, gradient (5 kinds), sprite (with full uGUI Image parity) and procedural pattern.
  • Real strokes — inner/center/outer alignment, per-side toggles, dashes and stroke gradients.
  • Per-corner radii — uniform or all four independently, plus a squircle/superellipse exponent.
  • Silhouette masking — LcShapeMask masks children to the exact shape with a feathered edge.
  • Pixel-accurate raycasting — clicks inside the bounding box but outside the shape pass through.
  • Theme-aware — fills and gradients can reference design tokens instead of literal colours.
  • Style presets — save a configured look as an asset and reapply it anywhere.
Scope. Lumina Shapes is the shape and geometry pack. It bundles the Lucent render spine, motion engine and theme runtime because the shapes depend on them — but it does not include blur, glass or shadow effects (that is Lumina Glass UI), widgets, charts or scroll views.

Quick Start

The fastest path is the GameObject menu, which creates a correctly configured shape under the selected Canvas:

Menu commandCreates
GameObject → Lucent UI → ShapeA bare LcShape to configure yourself.
GameObject → Lucent UI → Rounded PanelRounded rect, panel proportions.
GameObject → Lucent UI → CircleCircle.
GameObject → Lucent UI → Pill (Capsule)Capsule / pill.

Or add Add Component → Lucent UI → Lc Shape to any RectTransform under a Canvas.

using Lucent.Shapes;
using Lucent.Render;

var shape = go.AddComponent<LcShape>();

shape.ShapeKind = LcShapeKind.RoundedRect;
shape.SetUniformRadius(16f);
shape.SetFillColor(new Color32(38, 132, 255, 255));
shape.SetStroke(enabled: true, width: 2f);

LcShape derives from LcDrawable, which is a uGUI MaskableGraphic — so it participates in Canvas batching, masking and the raycast system like any built-in Image.

Squircles

SuperellipseExponent (default 5) controls how a rounded rect blends from a circular corner into a true superellipse. Raising it produces the continuous-curvature "squircle" corner used by modern mobile UI; a value of 2 is a plain ellipse-cornered rect.

Anti-aliasing

AaWidth (default 1) is the analytic edge feather in pixels, carried in the geometry rather than resolved by MSAA. That is why a shape stays clean when the Canvas scales, when it is rotated, and on devices with no MSAA budget. Set it to 0 for a hard pixel edge in a deliberately aliased art style.

Fills, Gradients & Patterns

LcShapeStyle holds everything about how a shape is painted. Reach it through shape.Style.

SpriteA sprite with full uGUI Image parity.
PatternProcedural grid, checker or stripe.

Gradients

var style = shape.Style;

style.Fill           = LcFillKind.Gradient;
style.GradientKind   = LcGradientKind.Linear;
style.GradientColorA = new Color32(124,  58, 237, 255);
style.GradientColorB = new Color32( 34, 211, 238, 255);
shape.SetGradientAngle(45f);

Sprite fill

When Fill is Sprite, the shape reproduces uGUI Image behaviour: LcImageType selects Simple, Sliced, Tiled or Filled; LcImageFillMethod selects Horizontal, Vertical, Radial90, Radial180 or Radial360; and FillAmount plus PreserveAspect behave exactly as you expect. The difference is that the sprite is clipped to the procedural silhouette — a photo in a squircle needs no pre-masked texture.

Patterns

style.Fill          = LcFillKind.Pattern;
shape.SetPattern(LcPatternKind.Checker);   // None | Grid | Checker | Stripe
style.PatternScale  = new Vector2(12f, 12f);
style.PatternColorA = Color.white;
style.PatternColorB = Color.black;
style.PatternAngle  = 45f;

Strokes & Corners

Stroke alignment

LcStrokeAlignThe stroke sits…
InnerEntirely inside the shape bounds — outer size unchanged.
CenterStraddling the edge, half in and half out (default).
OuterEntirely outside — the shape grows by the stroke width.

Inner is usually what you want inside a layout group, because the element's footprint stays exactly what the layout computed.

Per-side and dashed strokes

var style = shape.Style;

shape.SetStroke(enabled: true, width: 2f);
style.StrokeAlign  = LcStrokeAlign.Inner;
style.StrokeColor  = new Color32(255, 255, 255, 40);

// Underline only
style.StrokeSideTop = style.StrokeSideLeft = style.StrokeSideRight = false;
style.StrokeSideBottom = true;

// Dashes
style.Dashed     = true;
style.DashLength = 8f;
style.DashGap    = 4f;

A stroke can also carry its own gradient, independent of the fill:

shape.SetStrokeGradient(true, new Color32(124,58,237,255), new Color32(34,211,238,255), angleDeg: 90f);
bool usesGradient = shape.StrokeUsesGradient;

Corners

using Lucent.Render;

shape.SetUniformRadius(16f);                          // all four
shape.SetCornerRadii(new LcCorners(16f, 16f, 0f, 0f)); // TL, TR, BR, BL  -- e.g. a tab

var uniform = LcCorners.Uniform(12f);
float biggest = uniform.Max;
var safe = uniform.Clamped(rect.height * 0.5f);       // never exceed half the short side

LcCorners orders its fields TL, TR, BR, BL — clockwise from the top-left, matching CSS. Radii larger than half the shorter side are clamped during generation, so an over-large radius degrades to a capsule instead of producing inverted geometry.

Shape Masks

LcShapeMask masks child graphics to a procedural shape silhouette with a soft, feathered edge — the thing uGUI's rectangular Mask cannot do without a texture.

Add it: Add Component → Lucent UI → Lc Shape Mask, with LcShapeMaskTarget on the children you want clipped.

ComponentRole
LcShapeMaskOwns the silhouette and the feather; masks its subtree.
LcShapeMaskTargetMarks a child as participating in the mask.
LcShapeSoftMaskThe pure coverage maths behind the feathered edge.

LcShapeSoftMask.Coverage turns a point plus a silhouette into a 0–1 coverage value, computed from the unsigned distance to the nearest polygon edge. It is a static function over values, so mask behaviour is unit-testable without a Canvas.

Avatar in one step. A circular profile picture is an LcShape (Circle) with an LcShapeMask, and the raw photo as a child. No pre-masked texture, no render texture, no extra draw call for the mask shape itself.

Pixel-Accurate Raycasting

LcShape implements ICanvasRaycastFilter. A click inside the RectTransform but outside the actual shape passes through to whatever is behind it — so a circular button is circular to the pointer, not square.

// Automatic through the uGUI event system:
bool hit = shape.IsRaycastLocationValid(screenPoint, eventCamera);

// Or test in local space yourself:
bool inside = shape.ContainsLocalPoint(localPoint, rect);

This matters most for overlapping non-rectangular UI — hex grids, radial menus, star ratings — where rectangular hit boxes overlap and the wrong element receives the click.

Silhouette access

LcShape also implements ILcSilhouetteSource, exposing its outline to other systems:

var points = new List<Vector2>();
if (shape.TryGetSilhouette(rect, points))
{
    // points is the closed outline in local space
}

int version = shape.SilhouetteVersion;   // bump = silhouette changed; cache against this

SilhouetteVersion is the cheap change check: cache derived work against it and recompute only when it increments. It is the same contract Lumina Glass UI uses to fit a shadow or glow to a shape without re-deriving the outline every frame.

Theme Tokens

The Lucent theme runtime ships inside this pack, so a shape can reference a design token instead of a literal colour. Change the token and every shape using it follows.

using Lucent.Theme;

shape.Theme = myTheme;                       // or leave null to use the global active theme
LcTheme effective = shape.EffectiveTheme;

shape.Style.FillTokenId = LcColorKeys.Surface;   // solid fill from a token
shape.SetFillGradientToken(LcGradientKeys.Primary);

Color32 resolved = shape.ResolveFillColor();

EffectiveTheme resolves the local override first and falls back to LcThemeManager.Active, so most shapes leave Theme empty and simply follow the app-wide theme.

Full theming tools. This pack contains the theme runtime. The visual Theme Designer window, palette import, WCAG contrast helpers and the built-in semantic themes are part of Lumina Theme. Both install to the same folder and share the same runtime files, so adding Lumina Theme later upgrades the tooling without touching your shapes.

The Render Spine

Every shape is a generator writing backend-neutral geometry into a draw list, which a surface turns into one native mesh. Understanding this is optional for normal use and essential if you want to add your own shape.

using Lucent.Render;

var list = new LcDrawList();
var ctx  = new LcDrawContext(rect, list);
generator.Generate(ctx);              // ILcShapeGenerator -> LcDrawList

ILcRenderSurface surface = GetComponent<LcUGuiSurface>();
surface.Submit(list);                 // one CanvasRenderer mesh

Writing a custom shape

Implement ILcShapeGenerator (or derive from LcShapeGeneratorBase) and write vertices into the context. Your generator then gets strokes, gradients, masking, raycasting and theming for free, because those all operate on the draw list rather than on any particular shape.

Editor Tools

Shape inspector

The custom inspector shows only the parameters the current ShapeKind actually uses — Sides appears for polygons and stars, arc angles for arcs and pies — so the panel never presents fields that do nothing. A live preview renders the shape as configured, and RebuildFromInspector() is the hook if you drive the style from your own editor code.

Shape Style Presets

Save a configured look as an asset and reapply it across a project:

Assets → Create → Lucent UI → Shape Style Preset

A preset captures the whole LcShapeStyle — fill, gradient, pattern, stroke, corners — which makes it the practical way to keep one card look consistent across dozens of prefabs without nesting them.

Performance notes

Geometry is rebuilt only when something actually changes, not per frame. Shapes sharing a material batch normally through LcMaterialCache. A shape with a pattern or gradient fill costs one mesh and one material — the same order as an Image, without the texture memory a comparable sprite would need.

FAQ & Troubleshooting

My shape is invisible.

Check it is under a Canvas, that the RectTransform has non-zero size, and that FillColor alpha is not 0. A FillTokenId pointing at a missing token resolves to the theme's fallback colour, which is often not what you expect.

The corners look wrong at small sizes.

A radius larger than half the shorter side is clamped, so an aggressive radius on a short element becomes a capsule. Use LcCorners.Clamped() to make that explicit in your own code.

Edges look soft / blurry.

That is AaWidth (default 1 pixel). Set it to 0 for hard edges. If edges look soft only at certain scales, check the Canvas reference resolution — the feather is in pixels.

Clicks are not passing through the transparent corners.

Pixel-accurate hit testing runs through ICanvasRaycastFilter, which requires Raycast Target to be enabled on the graphic. If a parent has its own raycast filter it may answer first.

My mask has a hard edge.

Confirm children carry LcShapeMaskTarget, and check the feather width on the mask. A feather of 0 is a hard silhouette by design.

Can I use my own outline?

Yes — LcShapeKind.Path takes an arbitrary point list and triangulates it with LcPolygonTriangulator. For something more structural, implement ILcShapeGenerator.

Do shapes batch?

Yes, on the same rules as any uGUI graphic: same material and texture, no intervening element that breaks the batch. LcMaterialCache shares materials so identical styles do not each create their own.

Does this need URP?

No. Lumina Shapes has no render-pipeline dependency. Only Lumina Glass UI, which does GPU blur, requires URP for its blur path.
